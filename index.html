Canvas URL
Canvas API Token
Treat this token like a password — whoever has it can see and do anything your Canvas login can, not just assignments. StudyFlow only uses it to pull your assignments, syllabi, and grades; it's never shared. You're always in control: you can revoke it anytime from Canvas → Settings → Approved Integrations, independent of StudyFlow.
How to get your token
1. Log into Canvas
2. Click your profile picture
3. Go to Settings
4. Scroll to "Approved Integrations"
5. Click "+ New Access Token"
6. Name it "StudyFlow" and paste it above

Canvas connected
Your Canvas token works like a password — StudyFlow only uses it to read your assignments, syllabi, and grades, and never shares it. Note that Disconnect Canvas removes it from StudyFlow only — the token itself stays active in Canvas until you also remove it there, under Canvas → Settings → Approved Integrations.
Canvas URL
Canvas API Token
Treat this token like a password — StudyFlow only uses it to pull your assignments, syllabi, and grades, and never shares it. You can revoke it anytime from Canvas → Settings → Approved Integrations, independent of StudyFlow.
Make sure you're already logged into your school's Canvas in a browser tab before you start.
1
In Canvas, click your profile picture or name in the top-left corner of the screen.
2
Choose Settings from the menu that appears.
3
Scroll all the way down to the Approved Integrations section near the bottom of the page.
4
Click + New Access Token. For the purpose, type anything — "StudyFlow" works great.
5
Click Generate Token, copy the long token shown, and paste it into the field above. Canvas only shows it once!
